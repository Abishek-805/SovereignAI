# Current source release — 2026-10-10

This release includes automatic inference-asset setup, the backend RAG repairs, frontend answer lifecycle integration, and regression tests. Start the project using the launcher documented in the root README. Binary weights and runtime downloads are pinned in `model-assets.json`.

RAG evidence review requires every draft claim ID, uses source-bound span references instead of generated quotation text, and retains citation, numerical and semantic checks. Exact-ID operations run against authorized complete source records. Numeric values are not treated as categorical identity filters; rationale requests follow evidence assessment rather than being answered by a raw lookup.

Terminal results clear drafts and loading controls. Staging browser checks covered overview generation, missing rationale, exact-ID calculations, missing ID/file errors, cancellation, and history reopening. The backend regression suite passed 269 tests; the bounded frontend suite passed 728 tests across 61 files. These checks establish the recorded staging behavior, not universal semantic correctness.

Production acceptance remains unverified for the final staging corrections. Docker availability/isolation verification blocked a fresh code-agent generation test. An earlier unexplained service disappearance also requires a longer stability check. A clean-machine GPU startup has not been executed. Do not represent this source publication as production acceptance.

The release publishes application source, tests, setup tooling and experiment source. Uploaded documents, full live request traces, rollback snapshots, generated training bundles, model files and runtime binaries remain local. Those artifacts can contain personal information or large machine-specific data. Existing protected receipts and the canonical training dataset were not changed; no training was started.

Some experiment scripts depend on local evidence paths and are not standalone public benchmarks without their authorized fixtures. Frozen comparison results are not regenerated by setup. Keep `RUN_TRAIN=False` unless a separate training run is explicitly authorized.
