# Windows keyboard shortcuts

These bindings work in the SovereignAI web workbench. Open **Code → Shortcuts** for the same reference in the app. Browser or operating-system reserved shortcuts can take precedence in some embedded web views.

| Action | Shortcut |
| --- | --- |
| Chat | `Ctrl+Alt+1` |
| Knowledge | `Ctrl+Alt+2` |
| Agent | `Ctrl+Alt+3` |
| Code | `Ctrl+Alt+4` |
| Downloads | `Ctrl+Alt+5` |
| Control Center | `Ctrl+Alt+6` |
| Control Center → Runtimes | `Ctrl+Alt+7` |
| Quick-open file in Code | `Ctrl+P` |
| Code command palette | `Ctrl+Shift+P` or `F1` |
| Show Code Explorer | `Ctrl+Shift+E` |
| Search current project | `Ctrl+Shift+F` |
| New Code file | `Ctrl+N` |
| Save Code file | `Ctrl+S` |
| Rename / delete focused Explorer file or folder | `F2` / `Delete` |
| Copy / cut / paste focused Explorer file or folder | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Close Code tab | `Ctrl+W` |
| Next / previous Code tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Run active Code file | `F5` |
| Focus Code terminal | `` Ctrl+` `` |
| Toggle Code Explorer | `Ctrl+B` |
| Toggle Code output | `Ctrl+J` |
| Toggle Code assistant | `Ctrl+Alt+B` |
| Apply assistant change | `Ctrl+Enter` in the assistant input |
| Exit full-screen Code / dismiss open menu or dialog | `Esc` |

The editor also supports its built-in Windows text-editing shortcuts, including selection, undo, redo, find, and save. The Explorer, assistant, and terminal boundaries can be dragged; a focused boundary moves by 20 pixels with the arrow keys.

SovereignAI implements the actions listed here. It does not include the full Visual Studio Code extension, debugger, or source-control system.
