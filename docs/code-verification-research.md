## Evidence from primary research and official documentation

- [Chen et al., Teaching Large Language Models to Self-Debug, v2](https://arxiv.org/abs/2304.05128v2): execution results and code explanations improve benchmark performance; reported gains include 2–3 percentage points on Spider and up to 12 points on TransCoder/MBPP. Limits: benchmark/model-specific few-shot results, not evidence that a small local model or explanation can certify arbitrary code or module boundaries.
- [Olausson et al., Is Self-Repair a Silver Bullet for Code Generation?, v5](https://arxiv.org/abs/2306.09896v5): cost-adjusted self-repair gains on HumanEval/APPS with Code Llama, GPT-3.5, and GPT-4 are often modest, variable, or absent; feedback quality is a bottleneck. Limit: does not establish a universally optimal repair budget or validate this router. Prefer concrete external diagnostics before increasing generations.
- [Liu et al., EvalPlus](https://arxiv.org/abs/2305.01210): HumanEval+ expands tests by 80× using generated inputs and mutation. Limit: expanded tests still depend on valid specifications/oracles and do not prove completeness; this supports future contract coverage, not retroactively altering the frozen comparison.
- [Ruff F821 official rule](https://docs.astral.sh/ruff/rules/undefined-name/): checks undefined names likely to raise `NameError`; directly relevant to the service defect. Limit: static name checking does not establish payload behavior, correct delegation, or algorithm correctness. [Official configuration](https://docs.astral.sh/ruff/configuration/) documents `--isolated`, which ignores project configuration; a trusted validation policy should not be silently disabled by candidate config. Analyzer version, selected rules, suppression handling, and availability must be explicit.
- [Python AST documentation](https://docs.python.org/3/library/ast.html): `ast.parse` does not perform scoping checks and parsing is not execution. Limit: simple AST call/import checks can provide architecture evidence but miss aliases/dynamic dispatch; do not implement a homemade general undefined-name checker or treat AST agreement as proof.
