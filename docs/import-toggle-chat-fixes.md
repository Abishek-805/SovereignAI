# Project imports and conversation fixes — 28 September 2026

## Changes

- Project imports now accept mixed source and binary files through byte-preserving uploads. Both file and folder picker controls were exercised in the production application. Files are stored in the project's host folder under Documents/SovereignAI/Projects, including nested relative paths.
- Imports support 20 MiB per file and 256 MiB per workspace. Existing paths are never overwritten. Images have a read-only preview and original download; other binary files can be downloaded. UTF-8 files up to 2 MiB can use the editor. Generated edits retain their smaller bounds and cannot replace binary assets.
- IndexedDB writes snapshot Svelte reactive records, including nested routing metadata and connected document references. Knowledge can be switched off after an answer has populated conversation history, and its state survives reload.
- Removed the repeated document-name lists from Chat and Agent messages, the Chat mode explanation, and Agent's routing/raw evidence diagnostic panels. Connected context, actual source citations, downloadable artifacts and stored backend telemetry remain available.
- The bounded model planner uses a shorter prompt, document names without UUIDs, and JSON-only grammar from its first generated token. This avoids the hidden reasoning that delayed short questions. Answers are generated by the model; there is no greeting-response dictionary. Evidence-dependent questions still route to retrieval.
- The owned runtime uses the documented 1024 MiB fitting margin, replacing the previous 512 MiB setting that could leave it below the admission reserve during desktop use. It stays warm for ten minutes of inactivity instead of one minute, then sleeps to release resources. Verified leases check these launch settings. The 256 MiB emergency admission reserve remains enforced; unrelated resource pressure can still cause a legitimate refusal.

## Timing and remaining bounds

The warm production Chat identity request completed in **5.465 seconds**. The preceding first request took **13.292 seconds**, so cold/non-inference overhead has not disappeared. One direct greeting probe fell from 26.96 seconds with hidden reasoning to 2.50 seconds with JSON-only output. These are single observations, with different runtime state and possible concurrent verification load, not a guaranteed speedup or latency SLA.

Import/storage limits differ from the existing bounded Docker execution limits (1 MiB per input file, 8 MiB total). Larger assets can be stored and previewed; an oversized execution input is still refused. No full VS Code parity or production-context memory guarantee is claimed.

Automatic approval review blocked recursive removal of the benchmark's temporary project folders. The clearly named suite-owned projects remain as test fixtures. Existing user projects, including Summa, were not changed.
