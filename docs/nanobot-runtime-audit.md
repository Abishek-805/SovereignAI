## Recommendation for the constrained hybrid

Adopt the runtime separation, immutable turn admission, actual tool-feedback replay, checkpoint/progress events and session ownership concepts through narrow interfaces. Keep SovereignAI authoritative for workspace selection, model registry/lease/unload, resource admission, Docker isolation, independently validated completion, staged review and Accept publication. A Nanobot runner may request these existing capabilities; it should not create a second unrestricted shell/files path or independent model launcher. Sequential planner/coder/checker roles can share one resident worker when suitable. Do not infer correctness from more subagents, a final reply, optional budget-exhausted finalization or error fallback. No superiority claim, benchmark gain, or runtime compatibility has been established by this source audit.
